Processing

1 · Echo processing
The window defaults to −200 to +200 µm (+ z = + frequency = closer to the magnet). Clear both ends to use the region where the profile exceeds 10% of its maximum. Exponential fits are done every Exp-fit spacing µm (blank = the natural resolution 1/(points × dwell × γG); zero-filling interpolates but adds no resolution). The ILT is cheap, so by default it is run at every zero-filled point to match the heat maps. Positions whose signal is below Min signal are not fitted (they would only fit noise) and show as gaps. The window-summed decay is also fitted, as a reference.
2 · Decay analysis (choose any)

Larger α = less smoothing (noisier spectrum); typical range 1e6–1e10. The grid never has more points than echoes. Peaks below the threshold are ignored in the peak table.

Uncertainty

Fit confidence intervals

From the least-squares covariance of the multi-exponential fit (Student-t intervals), at every position in FT mode.

Decay to analyse (for MCMC and bootstrap)
MCMC (Bayesian posterior of the multi-exponential fit)
Uses the model chosen on the Process tab. Priors: amplitudes flat and ≥ 0; T₂ log-uniform between a tenth of the first and ten times the last echo time, ordered fast → slow so components cannot swap; offset flat; σ log-uniform if sampled. Intervals are central credible intervals at the level above. The default 6000 steps is about 100 autocorrelation times for a typical decay; strongly correlated parameters (a window shorter than T₂) need more, and the page warns when the chain is too short.
Bootstrap (refit surrogate decays)
Each replicate is the fitted curve plus resampled noise, refitted. The preferred noise source resamples the values actually measured in the imaginary channel (it contains only noise after phasing), so no Gaussian assumption is needed. Real-valued data falls back to residual resampling.

MCMC and the bootstrap run after the processing, on the Results tab, once you have seen a time estimate and confirmed.
