Processing

1 · Echo processing
The window defaults to −200 to +200 µm (+ z = + frequency = closer to the magnet). Clear both ends to use the region where the profile exceeds 10% of its maximum. Exponential fits are done every Exp-fit spacing µm (blank = the natural resolution 1/(points × dwell × γG); zero-filling interpolates but adds no resolution). The ILT is cheap, so by default it is run at every zero-filled point to match the heat maps. Positions whose signal is below Min signal are not fitted (they would only fit noise) and show as gaps. The window-summed decay is also fitted, as a reference.
2 · Decay analysis (choose any)

Larger α = less smoothing (noisier spectrum); typical range 1e6–1e10. The grid never has more points than echoes. Peaks below the threshold are ignored in the peak table.
